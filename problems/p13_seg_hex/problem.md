# p13_seg_hex 十六进制七段数码管译码器

## 数电来源
- 数电讲义·组合逻辑电路（二）—— **1.2 译码器**（转码器：按规则转换编码，如七段数码管译码器）
- Logisim 必做：**搭建七段数码管译码器（0）**（十进制 0-9）与 **（1）**（十六进制 0-F）
  —— 本题即十六进制完整版（涵盖十进制的 0-9，并多出 A b C d E F 六位字母）。

## 回扣 Logisim
你在 Logisim 里填过这张转码表（每个输入的七段亮灭）。还记得吗：七段引脚一般按
**abcdefg** 编号（a 是顶端横段，顺时针 b、c、d，再逆时针 e、f，中间段 g）。
本题固定 `seg[6:0]` 的位序就是 **seg[6]=a, seg[5]=b, …, seg[0]=g**。

## 模块接口
```verilog
module seg_hex(
    input  logic [3:0] d,     // 十六进制 0..F
    output logic [6:0] seg    // seg[6:0] = abcdefg，a 为最高位
);
```
