# p04_cmp_eq4 四位相等比较器

## 数电来源
- 数电讲义·组合逻辑电路（一）—— **2.4 比较器**（"利用异或门/同或门判断相等"）
- Logisim 必做：**搭建比较器（0）**——"根据给出的电路结构图，搭建四位比较器（判断相等）"

## 回扣 Logisim
Logisim 里那张结构图的思路是：**逐位异或 → 每一位的异或结果再或起来 → 取反**。
即"a 与 b 每一位都不相异，则相等"。`eq` 为 1 当且仅当 `a == b`。

## 模块接口
```verilog
module cmp_eq4(
    input  logic [3:0] a,
    input  logic [3:0] b,
    output logic       eq    // 1: a 与 b 相等；0: 不相等
);
```
