# p08_prio_enc8_3 8-3 优先编码器

## 数电来源
- 数电讲义·组合逻辑电路（二）—— **1.1 编码器**（优先编码器：允许输入多 1，只对优先级最高的 1 编码）
- Logisim 必做：**搭建编码器（2）**——"利用 4-2/8-3 优先编码器原理，自行列真值表、求逻辑表达式并化简"

## 回扣 Logisim
讲义里给出过 8-3 优先编码器低位 `Y0` 的化简结果：
`Y0 = I7 + I5·!I6 + I3·!I4·!I6 + I1·!I2·!I4·!I6`
你当时用卡诺图/公式法推出过整组表达式。本题可以直接用布尔化简式，
也可以用条件表达式逐级判断（看得最清楚）：**从高位开始，谁最高谁是老大**。

## 模块接口
```verilog
module prio_enc8_3(
    input  logic [7:0] i,     // 8 个输入，可多位为 1
    output logic [2:0] y      // 优先级最高（位号最大）的 1 的下标
);
```
