# p10_decoder3_8 3-8 译码器

## 数电来源
- 数电讲义·组合逻辑电路（二）—— **1.2 译码器**（编码器的逆操作：将二进制数转换为独热码）
- Logisim 必做：**搭建译码器（1）**——"实例化 2-4 译码器，搭建 3-8 译码器"

## 回扣 Logisim
Logisim 里你是用两片 2-4 译码器拼出 3-8 的（高位做使能/选择）。本质就是**最小项**：
3 位输入 a 共有 8 个最小项，每个最小项对应输出的一个 bit。本题用逐位 assign 写出 8 个最小项即可，
无需实例化。

## 模块接口
```verilog
module decoder3_8(
    input  logic [2:0] a,     // 3 位二进制输入
    output logic [7:0] y      // 8 位独热输出
);
```
